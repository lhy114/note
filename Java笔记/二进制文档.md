好，我们这次把它当成一个“游标不断向右移动”的解析过程。你只需要记住：

```
xxd 左边      中间                右边
偏移量        十六进制字节        ASCII 显示
```

右边的 `java/l`、`Hello` 只是对可打印字节的辅助显示，不是单独的数据结构。

**第 1 步：固定文件头**

先看前 8 个字节：

```
00000000: ca fe ba be 00 00 00 46 00 1f
```

从偏移 `0x000` 开始读：

```
0x000: CA FE BA BE    magic
0x004: 00 00          minor_version = 0
0x006: 00 46          major_version = 70
0x008: 00 1F          constant_pool_count = 31
```

多字节整数按大端序读取：

```
00 46 = 0x0046 = 70
00 1F = 0x001F = 31
```

版本 70 对应 Java 26。常量池编号从 `1` 开始，所以常量池实际上是 `#1` 到 `#30`。

**第 2 步：从 0x00A 开始读常量池**

常量池第一个字节是 `tag`。这份文件只出现六种 tag：

```
01  Utf8
07  Class
08  String
09  Fieldref
0A  Methodref
0C  NameAndType
```

现在游标 `p = 0x00A`：

```
0x00A: 0A 00 02 00 03
```

`0A` 表示 `Methodref`，后面两个 `u2` 是引用：

```
#1 = Methodref #2.#3
```

读完 5 个字节后：

```
p = 0x00F
```

继续：

```
0x00F: 07 00 04

#2 = Class #4
```

`07` 是 Class，`0004` 指向 `#4`。游标到 `0x012`。

```
0x012: 0C 00 05 00 06

#3 = NameAndType #5:#6
```

`0C` 是 NameAndType。游标到 `0x017`。

接下来是 UTF-8 字符串：

```
0x017: 01 00 10 6A 61 76 61 2F 6C 6F 62 6A 65 63 74
```

读取方式：

```
01        tag = Utf8
00 10     length = 16
后面 16 字节 = java/lang/Object
```

所以：

```
#4 = Utf8 "java/lang/Object"
```

游标到 `0x02A`。

```
0x02A: 01 00 06 3C 69 6E 69 74 3E

01        Utf8
00 06     length = 6
字节内容  <init>

#5 = Utf8 "<init>"
```

再往后：

```
0x033: 01 00 03 28 29 56

#6 = Utf8 "()V"
```

到这里，前六个常量已经读完了：

```
#1 Methodref #2.#3
#2 Class #4
#3 NameAndType #5:#6
#4 Utf8 java/lang/Object
#5 Utf8 <init>
#6 Utf8 ()V
```

它们共同表示：

```
java/lang/Object.<init>:()V
```

也就是父类 `Object` 的构造方法。

**第 3 步：继续读剩余常量池**

后面规则完全一样，不再换规则。

`#7` 到 `#12` 描述 `System.out`：

```
#7  Fieldref #8.#9
#8  Class #10
#9  NameAndType #11:#12

#10 Utf8 java/lang/System
#11 Utf8 out
#12 Utf8 Ljava/io/PrintStream;
```

合起来就是：

```
java/lang/System.out:Ljava/io/PrintStream;
```

`#13` 和 `#14` 是源码里的字符串：

```
#13 String #14
#14 Utf8 "Hello World"
```

这里要注意层级：

```
#13 是 CONSTANT_String
#14 是真正的 UTF-8 字节内容
```

`#15` 到 `#20` 描述 `println`：

```
#15 Methodref #16.#17
#16 Class #18
#17 NameAndType #19:#20

#18 Utf8 java/io/PrintStream
#19 Utf8 println
#20 Utf8 (Ljava/lang/String;)V
```

合起来：

```
java/io/PrintStream.println:(Ljava/lang/String;)V
```

`#21` 到 `#30` 主要是当前类和调试信息：

```
#21 Class #22          HelloWorld
#22 Utf8               HelloWorld
#23 Utf8               Code
#24 Utf8               LineNumberTable
#25 Utf8               LocalVariableTable
#26 Utf8               this
#27 Utf8               LHelloWorld;
#28 Utf8               main
#29 Utf8               SourceFile
#30 Utf8               HelloWorld.java
```

常量池结束后：

```
p = 0x147
```

**第 4 步：读取类级信息**

从 `0x147` 开始：

```
0x147: 00 21    access_flags
0x149: 00 15    this_class
0x14B: 00 02    super_class
0x14D: 00 00    interfaces_count
0x14F: 00 00    fields_count
0x151: 00 02    methods_count
```

逐项解释：

```
access_flags = 0x0021
```

表示：

```
ACC_PUBLIC  = 0x0001
ACC_SUPER   = 0x0020
```

所以：

```
this_class = #21  -> HelloWorld
super_class = #2  -> java/lang/Object
interfaces_count = 0
fields_count = 0
methods_count = 2
```

虽然源码只写了 `main()`，但编译器自动生成了构造方法，所以这里有两个方法。

**第 5 步：读取第一个方法**

第一个方法从 `0x153` 开始：

```
access_flags     = 0001
name_index       = 0005
descriptor_index = 0006
attributes_count = 0001
```

解析：

```
access_flags = public
name_index = #5 = <init>
descriptor_index = #6 = ()V
```

这就是自动生成的构造方法。

它有一个 `Code` 属性，字节码是：

```
0: 2A          aload_0
1: B7 00 01    invokespecial #1
4: B1          return
```

对应：

```
aload_0                 加载 this
invokespecial #1        调用 Object.<init>
return                  返回
```

构造方法后面还有：

```
LineNumberTable
LocalVariableTable
```

其中 `LocalVariableTable` 记录了：

```
槽位 0 = this
类型   = LHelloWorld;
```

**第 6 步：读取 main 方法**

第二个方法从 `0x190` 开始：

```
access_flags     = 0009
name_index       = 001C
descriptor_index = 0006
attributes_count = 0001
```

解析：

```
access_flags = public static
name_index = #28 = main
descriptor_index = #6 = ()V
```

所以它对应源码：

```
public static void main()
```

它的 Code 字节码在：

```
000001a0: 00 00 00 00 00 09 b2 00
000001a8: 07 12 0a b6 00 0f b1
```

整理后：

```
0: B2 00 07    getstatic #7
3: 12 0A       ldc #10
5: B6 00 0F    invokevirtual #15
8: B1          return
```

逐条看：

```
getstatic #7
```

读取：

```
#7 = System.out
```

```
invokevirtual #15
```

调用：

```
PrintStream.println(String)
```

但是中间这条：

```
ldc #10
```

有问题。`#10` 是：

```
#10 = Utf8 "java/lang/System"
```

`ldc` 不应该加载一个 `Utf8` 常量。源码真正想要的是：

```
#13 = String "Hello World"
```

所以这里本应是：

```
3: 12 0D    ldc #13
```

当前文件里写的是：

```
3: 12 0A
```

对应原始偏移：

```
0x1AA: 0A
```

如果改成：

```
0x1AA: 0D
```

`ldc` 才会加载 `#13`，然后 `#13` 再指向 `#14` 的 `"Hello World"`。

**第 7 步：读取文件末尾**

`main` 的 Code 属性后面还有行号表：

```
LineNumberTable
  pc=0 -> 源码第 4 行
  pc=8 -> 源码第 5 行
```

最后是类级属性：

```
attributes_count = 1
attribute = SourceFile
sourcefile_index = #30
```

所以源文件是：

```
HelloWorld.java
```

整个读取路径就是：

```
magic
minor_version
major_version
constant_pool_count
constant_pool[]
access_flags
this_class
super_class
interfaces[]
fields[]
methods[]
attributes[]
```

你这份文件最后一个字节位于 `0x1CC`，长度正好是 `0x1CD`，也就是 461 字节。当前真正的异常点就是 `0x1AA` 的 `0A`，它把本来应该加载 `"Hello World"` 的 `ldc` 指向了 `java/lang/System` 的 UTF-8 常量。
