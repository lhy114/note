# 基础篇
## 优点和缺点
### 优点
1. 应用解耦, 说人话: 就是之前一个订单业务是同步的, 如果要执行完毕, 就要一次执行库存系统、支付系统、物流系统等, 带来的问题就是, 延迟较高, 这个业务与其他业务高耦合, 如果你还要添加一个新的功能就要重新写一个业务加入到订单系统中
2. 异步提速, 同理一, 提高了速度
3. 削峰填谷, 也就是当一个**缓存**, 将用户的请求存储到mq中
