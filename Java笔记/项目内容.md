HTTP 中的 **Bearer** 通常指的是 **Bearer Token（持有者令牌）认证方式**，它是 HTTP `Authorization` 请求头中的一种认证方案。

简单理解：

> **Bearer = "谁拿着这个 Token，谁就是合法用户"**

服务器不关心你是谁拿到的，只要你提供有效 Token，就允许访问。
