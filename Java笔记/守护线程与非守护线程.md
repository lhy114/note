JVM 里的线程分两类：

- **非守护线程（用户线程）**：正常执行任务的线程，比如 `main` 线程、业务线程。
- **守护线程**：后台辅助线程，比如 GC、JIT 编译线程。

JVM 的退出规则是：

```
只要还有非守护线程在运行，JVM 就不会退出
当最后一个非守护线程结束后，JVM 直接退出，守护线程会被强制终止
```

所以：

```
Executors.newSingleThreadExecutor();
```

创建出来的线程**默认是非守护线程**。如果你的任务写成 `while(true)`，主线程即使结束了，这个线程还在跑，JVM 就永远退不出去。

改成守护线程：

```
Executors.newSingleThreadExecutor(r -> {
    Thread t = new Thread(r);
    t.setDaemon(true);
    return t;
});
```

此时主线程结束，JVM 可以退出，守护线程会被直接杀掉。

注意：守护线程可能在任何时候被中断，所以它只适合“可以随时放弃”的后台任务。订单处理最好还是用 `running` 标志 + `@PreDestroy` 优雅退出，守护线程只是兜底。
