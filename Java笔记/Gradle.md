| 对比项  | Maven                                               | Gradle                                                  |
| ---- | --------------------------------------------------- | ------------------------------------------------------- |
| 配置文件 | `pom.xml`，XML                                       | `build.gradle` / `build.gradle.kts`，Groovy 或 Kotlin DSL |
| 核心模型 | 固定生命周期：`clean → compile → test → package → install` | 任务依赖图，可以灵活编排任务                                          |
| 配置方式 | 声明式，约定优于配置                                          | 声明式加脚本编程能力，更灵活                                          |
| 构建速度 | 中规中矩，大型多模块项目偏慢                                      | 增量构建、构建缓存、常驻守护进程，通常更快                                   |
| 学习成本 | 较低，规则固定                                             | 较高，DSL 和脚本自由度大                                          |
| 生态   | 老牌工具，很多老项目和公司内部标准用它                                 | 现代项目、Android 开发主流，Java 项目迁移趋势明显                         |
