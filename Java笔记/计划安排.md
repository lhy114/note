# 2026年8月—2027年秋招学习、科研与实习计划

## 一、总体目标

当前阶段的核心目标不是同时把所有事情做到最好，而是按照优先级完成以下四件事：

1. **完成 BIBM 第一篇论文的最终投稿与后续处理。**
    
2. **在 2026 年下半年完成第二篇论文并争取投稿。**
    
3. **完成 Java 后端技术栈和一个可用于求职的工程项目。**
    
4. **在 2026 年下半年争取获得第一段实习，为 2027 年大厂暑期实习和秋招做准备。**
    

核心路线：

> **BIBM 第一篇成果 → 第二篇论文进入投稿状态 → 第一段实习 → 2027 年大厂暑期实习 → 2027 年秋招**

---

# 二、时间分配原则

### 1. 不同时把所有事情作为主线

当前阶段只允许：

> **一个主线 + 一个副线 + 一个维护线**

当前主线：

> **Java 技术 + Java 工程项目 + 求职准备**

当前副线：

> **第二篇论文前期准备**

维护线：

> **八股、算法、笔试**

BIBM：

> **等待结果，只处理必要事项，不再无限扩展。**

---

### 2. 每天不追求 8 小时满负荷

目标：

> **每天 5～6 小时高质量学习/工作**

而不是每天强行 8 小时。

原则：

> **稳定坚持 > 短期爆肝**

每周保留至少半天到一天用于休息和恢复。

---

### 3. 不连续一个星期做同一件事

采用“多模块轮换”：

> Java 学习 ↔ 项目开发 ↔ 求职准备 ↔ 第二篇论文

避免连续一周只做论文或者只看 Java。
