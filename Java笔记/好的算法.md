```
    public static void main(String[] args) {  
        int[] arr = {2, 588, 888, 1000, 10000};  
        Random r = new Random();  
  
        // Fisher-Yates 洗牌：从后往前，每个位置和前面随机位置交换  
        for (int i = arr.length - 1; i > 0; i--) {  
            int j = r.nextInt(i + 1);   // 0 ~ i 之间的随机位置  
            int tmp = arr[i];  
            arr[i] = arr[j];  
            arr[j] = tmp;  
        }  
  
        // 洗完后，arr 已经是随机排列了，按顺序输出即可  
        for (int v : arr) {  
            System.out.println(v + "元的奖金被抽出");  
        }  
    }  
}
```

如果用我之前的思路，那么最大的时间复杂度就可能为O(n^2)了，因为使用fisher-yates算法，我们要如何降低时间复杂度呢，之前的想法并没有运用到数组的顺序特性，而是随机的抽签一个数然后进行判断（在模拟一个抽取的过程，但是我们抽取出来的数据，没有让剩下的概率变大，反而不变，也不想一个模拟的过程）；但是我们换一个思路：“一个序列1 2 3 .... i, i+1, ... , n”，前i-1个是已经抽取出来的位置，后面是我们带随机处理的序列。第i个位置 应该是\[i,n]位置里面随机一个数字，我们用随机数生成一个，然后将其搬到这个地方不久解决了吗。


### KMP算法，求子串的位置
1. 暴力求解String.contains，时间复杂度为O(m✖️n)
2. KMP，利于最长公共前后缀，next数组保存进行求解，时间复杂度为O(m+n)

```
第一次匹配到第 6 位发现 D 和空格不匹配：
文本:  ...A B C D A B _ A... i指针
模式:   A B C D A B D j指针
        0 1 2 3 4 5 6

暴力会想：算了，从文本的下一个字符 B 重新开始比。
KMP 会想：我已经知道模式前 6 位是 ABCDAB，
          它的"最长的相同前后缀"是 AB（长度 2），
          所以我可以直接把模式的前两位 AB 对齐到文本已经比过的 AB 上，
          文本指针不用回退。
```

这里最关健的是这里的next不匹配的时候情况怎么回溯，大部分没讲原理
B ！= C 但是我们此时知道ABA\[0,1,2] = ABA\[4, 5, 6] (由next数组可得知的)
然后ABA既然相同，那么他们的前缀和后缀也相同
既然如此，我们计算\[0,1,2]的前缀和后缀，也就等效于 \[0,1,2]的前缀和\[4,5,6]的后缀了，此时我们只需要按照之前的思路再次比较\[1]和最后一个位置


### Hash表
给定一个整数数组 `nums` 和一个整数目标值 `target`，请你在该数组中找出 **和为目标值** _`target`_  的那 **两个** 整数，并返回它们的数组下标。
你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。
你可以按任意顺序返回答案。

暴力求解你肯定会，但是你现在要想一下如何用空间换时间。用两层循环进行比较，我们只能得到一个数的信息，我们肯定会想到有一层循环肯定是多余的，那么如何用O（1）的时间得到想要的数据能。**此时就转换成了，如何在一堆数中找到我们想要的那一个数target-nums\[1]**，那么hash表就是解决这个事情的。

总结：如果有两个变量，我们尝试将一个变量替换为一个常数，遍历另外一个变量就行了。
