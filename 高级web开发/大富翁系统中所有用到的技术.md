## 大富翁系统中所有用到的技术

------

### Nginx是干什么的

**Nginx** 本质上是一个**高性能 Web 服务器 + 反向代理服务器**。它的核心作用就是4件事情：处理用户请求；反向代理；负载均衡；静态资源加速。

这里有一个问题，就是我们常说的反向代理，到底什么是反向代理呢，既然有反向代理，那应该就有正向代理。

#### 正向代理（forward proxy）：代理的是用户。

你 → 代理服务器 → 目标网站。你想访问某个网站，但你不直接去，而是找一个“代理服务器”帮你去访问

- 服务器不知道真正的用户是谁
- 只知道代理服务器

#### 反向代理（Reverse Proxy）：代理的是服务器。

用户 → Nginx → 后端服务器。用户访问的是代理服务器，但实际上服务在后面。

- 用户不知道真正的后端服务器是谁
- 只知道 Nginx

------

### 微服务

微服务（Microservices）= 把一个大系统拆成很多小服务。目的是：解耦、可拓展、高可用。

现在的问题就是，如果一个系统的服务太多了，我们改怎么去管理他们呢。例如：订单服务 要调用 用户服务。这个用户服务在哪一个机器、ip又是多少，挂了怎么办，这个时候就需要一个服务器的管理，也就是服务治理。

### Nacos就是做服务治理的。

Nacos 是“微服务的通讯录 + 配置中心”。他的核心两大功能：**服务注册与发现（服务在哪？）**

#### ① 服务启动时注册到 Nacos

```
用户服务 → 注册到 Nacos
订单服务 → 注册到 Nacos
```

------

#### ② 调用时去 Nacos 查

```
订单服务 → 问 Nacos：用户服务在哪？
           → 返回 IP + 端口
```

**配置中心（配置统一管理）**。配置中心这里可以详细讲解一下：

不统一管理会发生什么？假设你有一个微服务系统：

```
用户服务
订单服务
支付服务
CRM服务
ERP服务
```

 每个服务都有自己的配置文件：

```
用户服务 → application.yml
订单服务 → application.yml
支付服务 → application.yml
...
```

改配置很麻烦、文件有些不一致、环境混乱

比如数据库地址变了：你要改所有的配置文件。

### OpenFeign 是什么？

**OpenFeign** 让“服务调用服务”变得像“调用本地方法一样简单”

先看没有 Feign 的情况（你就知道它为什么存在）

在微服务里，服务之间要互相调用，比如：

```text
订单服务 → 调用 用户服务
```

------

传统写法（很麻烦）：

你要手动写 HTTP 请求：

```java
RestTemplate restTemplate = new RestTemplate();
String result = restTemplate.getForObject(
    "http://userservice/user/1", String.class);
```

👉 问题：

- URL 写死（不灵活）
- 代码重复
- 不优雅
- 不好维护

------

用了 OpenFeign 之后

👉 写法变成这样：

```java
@FeignClient("userservice")
public interface UserClient {

    @GetMapping("/user/{id}")
    User getUserById(@PathVariable("id") Long id);
}
```

调用时：

```java
userClient.getUserById(1L);
```

你感觉是在**调用本地方法**，
但实际上它在帮你发 **HTTP 请求**

------

OpenFeign 背后干了什么？

当你调用：

```java
userClient.getUserById(1L);
```

它其实做了这几步：

------

1️⃣ 去 Nacos 找服务地址

```text
userservice 在哪？
→ 返回 IP + 端口
```

------

2️⃣ 组装 HTTP 请求

```text
GET http://userservice/user/1
```

------

3️⃣ 发请求 + 拿结果五、OpenFeign 和微服务的关系

| 组件      | 作用   |
| --------- | ------ |
| 微服务    | 拆系统 |
| Nacos     | 找服务 |
| OpenFeign | 调服务 |

**Nacos 负责“找人”，OpenFeign 负责“打电话”**
