### 拳脚帧数

1. 轻拳（蹲轻拳）4帧发生，打防-2
2. 轻脚（蹲轻脚）5帧发生，打防-2
3. 中拳7帧发生，打防-3；蹲中拳6帧发生，打防-1；
4. 中脚9帧发生，打防-2；蹲中脚8帧发生，打防-6 ！！！（容易被差合）
5. 重拳9帧发生，打防+1；前重拳22帧发生，打防-3；蹲重拳8帧发生，打防-4
6. 重脚12帧发生，打防-4；蹲重脚11帧发生，打防-11（容易被差合）

注意：打康+2、确反康+4，绿冲+4，绿冲+打康为+6，绿冲+确反康+8

| ------- | --: | ---: | --: | --------: | ---: | ------: | ------- |

### 拳脚取消
| 起始招式     | 取消后接招    | 有利帧 | 后续可接              |
| -------- | -------- | --: | ----------------- |
| 轻拳 / 蹲轻拳 | 轻拳 / 蹲轻拳 |  +8 | 轻拳、轻脚、中拳（蹲中拳）、蹲中脚 |
| 轻脚 / 蹲轻脚 | 轻拳 / 蹲轻拳 |  +8 | 轻拳、轻脚、中拳（蹲中拳）、蹲中脚 |
| 中拳       | 中拳       |  +6 | 轻拳、轻脚、蹲中拳         |
|          | 蹲中拳      |  +9 | 轻拳、轻脚、中拳、中脚       |
|          | 中脚       |  +9 | 轻拳、轻脚、中拳、中脚       |
|          | 蹲中脚      |  +2 | —                 |
|          | 重拳       |  +6 | 蹲中拳、轻拳、轻脚         |
|          | 蹲重拳      |  +5 | 轻拳、轻脚             |
|          | 蹲重脚      | +40 | 倒地                |
|          | 轻拳 / 轻脚  |  +8 | —                 |
| 蹲中拳      | 同中拳取消    |   — | 继承中拳取消逻辑          |
|          | 重脚       |  +5 | 轻拳、轻脚             |
| 重拳 / 蹲重拳 | 任意拳脚     |   — | 可接任何拳脚            |

1. 轻拳取消后，只能接**轻拳（蹲轻拳）**，然后+8帧，此时可以接轻拳、轻脚，**中拳（蹲中拳）、蹲中脚**。
2. 轻脚取消后，只能接**轻拳（蹲轻拳）**，然后+8帧，此时可以接轻拳、轻脚，**中拳（蹲中拳）、蹲中脚**。
3. 中拳取消后，
	1. 接中拳，+6帧，可以接**轻拳轻脚，蹲中拳**
	2. 接蹲中拳，+9帧，可以接**轻拳轻脚、中拳中脚**
	3. 接中脚，+9帧，可以接**轻拳轻脚、中拳中脚**
	4. 接蹲中脚，+2帧
	5. 接重拳，+6帧，可以接**蹲中拳，轻拳轻脚**
	6. 接蹲重拳，+5帧，接轻拳轻脚
	7. 接蹲重脚，+40帧，倒地
	8. 接轻拳轻脚+8帧
4. 蹲中拳取消后，
	1. 同理中拳取消
	2. 接重脚，+5帧，轻拳轻脚
5. 蹲中脚取消后，
	1. 接中拳，+6帧
	2. 接蹲中拳，+9帧
	3. 接蹲中脚，+2帧
	4. 接轻拳轻脚+8帧
6. 重（蹲）拳取消后，可以接任何拳脚
